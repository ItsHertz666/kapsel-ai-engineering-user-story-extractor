# Artefak Produk Minggu 1

Sesuai ketentuan silabus dan modul perkuliahan (*02-modul-minggu-01-03.md*):
> *"Minggu 1–3: belum ada produk. Luaran berupa catatan proses dan pemahaman."*

Artefak luaran utama pada Minggu 1 adalah perumusan persoalan dan penentuan angka lingkup proyek:
1. Salinan berkas konsep persoalan: `peta-minat-calon-persoalan.md` (diunggah terpisah di root pengumpulan `docs/pengumpulan-lms/m1/`).
2. Kode Peserta: **K = 8** dengan batasan lingkup:
   - Dokumen rujukan: minimum 5 dokumen
   - Kasus uji: minimum 14 kasus uji
   - Tool minimum: 2 tool
   - Mode luaran tambahan: Wajib 1 mode ringkas (karena K genap)
   - Evaluator peer review: 2 rekan mahasiswa

Kode aplikasi (*backend* dan *frontend*) mulai dibangun pada fase implementasi lanjutan (Minggu 3 ke atas).
